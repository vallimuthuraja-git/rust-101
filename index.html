02 — Why do we need Rust?

Memory bugs = money

~70% of CVEs. Rust turns them into compile errors.

Fearless concurrency

C++ threads = roulette. Rust threads = checked. Discord killed GC pauses Go to Rust.

C-speed, no footguns

Python 20-100x slower. Rust = C speed, safe, no GC.

Cargo

build/test/fmt/clippy/doc in one tool. Errors that teach.

05/06 — What you can (and cannot) do / build

CAN do

  • Kernels, drivers, firmware
  • Fearless threads (tokio/rayon)
  • WASM in browser
  • C/C++ interop
  • Crypto, DBs, CLIs, cloud APIs

Honest limits

  • Borrow checker hurts 2-4 weeks
  • Slow compiles
  • No Java-inheritance (traits!)
  • AAA games C++; mobile UI Swift/Kotlin; notebooks Python

Rule: bug could kill / cost millions / page you at 3AM = Rust. Hackathon UI in 3h = Python/JS, rewrite hot part later.
